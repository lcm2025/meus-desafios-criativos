# meus-desafios-criativos
Repositório de desafios para curso N8N DIO

Atue como um especialista em N8N.

Crie uma automação para aviso de recebimento de tickets.

Público ou responsável:
Equipe de sustentação

Ferramentas envolvidas:
ServiceNow, Teams

Fluxo:
1. Abertura do ticket no ServiceNow para a mesa da equipe.
2. Recebimento do aviso da abertura do ticket no teams pessoal do analista.
3. Caso o ticket não seja assumido (fique sem designação de analista na mesa), deve ser enviado um novo aviso no Teams.

Regras:
Deve ser enviado um novo aviso a cada 10 minutos caso o ticket não seja designado para o analista.

Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.
